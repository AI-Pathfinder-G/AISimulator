This folder should contain the Kenney Mini Characters assets.
Download from: https://kenney.nl/assets/mini-characters

Expected files:
- mini_characters.glb (or .gltf + .bin)
- Animation clips: idle, walk, work, attack (etc.)
- Textures: baseColor, normal, metallicRoughness

To properly implement:
1. Download the actual asset pack from Kenney website
2. Extract the GLB/GLTF model and animations
3. Place them in this directory
4. Update the asset manifest and loading code
